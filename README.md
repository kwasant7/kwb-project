# KWB Project

A starter static website — plain HTML, CSS, and JavaScript. No build step, no dependencies.

**Live site:** https://kwasant7.github.io/kwb-project/

## Files

| File | What it is |
| --- | --- |
| `index.html` | The page markup and content |
| `styles.css` | All styling, including the light/dark theme variables |
| `script.js` | Theme toggle, demo counter, footer year |

## Running it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploying

GitHub Pages serves the `main` branch from the repository root. Push to `main` and the
live site updates within a minute or so.
